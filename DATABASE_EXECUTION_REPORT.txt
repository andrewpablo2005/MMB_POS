## IMPORTANT NOTES

1. **Supplier Data:** All supplier information has been removed from products table. Suppliers are now linked via inventory/batch table. This supports multiple suppliers per product.

2. **Pricing:** No pricing is stored in products anymore. All pricing (purchase_cost, markup, sale_price) is batch-level in inventory table. This allows different suppliers to provide same product at different prices.

3. **Quantity:** The column `quantity` has been renamed to `current_quantity` for clarity. This is the available stock after sales. `received_quantity` tracks the original batch size.

4. **FEFO Ready:** Expiry date is now properly indexed in inventory table for First-Expire-First-Out queries in POS.

5. **Backward Compatibility:** Existing transactions, returns, and discount data remain unchanged and compatible.

6. **Audit Trail:** New inventory_transactions table is ready to use for tracking all inventory movements (sales, returns, adjustments, damage).
